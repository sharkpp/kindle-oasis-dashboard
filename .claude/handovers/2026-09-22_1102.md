## 決定事項

- プロジェクトの目的: Kindle Oasis 第9世代の内蔵ブラウザで、JavaScript なしにダッシュボード画像を全画面表示・定期再読み込みするプロトタイプ
- 全画面表示は `html, body, img` を `width:100%; height:100%` にし、画像をビューポートと同画素数で生成して拡大・余白を回避する
- 定期再読み込みは `<meta http-equiv="refresh">` と HTTP `Refresh:` ヘッダの併用
- 画像は SVG を組み立てて sharp で 16 階調グレースケール PNG に変換（e-ink 向けに白背景・黒描画）
- ビューポート実測は `GET /probe.css` の `@media (min-width/min-height)` を使い、一致した背景画像の取得だけがサーバーに届く性質で JavaScript なしに検出する
- キャッシュ回避は画像 URL への毎回異なるトークン付与 + `Cache-Control: no-store`
- 初回描画サイズの既定値は 1264 x 1680 px（Oasis 第9世代のパネル解像度）
- 設定は環境変数 `PORT`（既定 3000）と `REFRESH_SEC`（既定 30）のみ

（以上はいずれも `README.md` と `package.json` に記録済みの内容。このセッションで新たに決めた事項はなし）
